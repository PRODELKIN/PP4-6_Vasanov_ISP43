# LibraryApp

Консольное приложение для учёта книг в библиотеке. Разработано на C# с целевой платформой .NET 8 в рамках практической подготовки № 4–6 по дисциплине «Инструментальные средства разработки программного обеспечения».

## Визуальная демонстрация

Приложение выводит результаты операций в консоль:

- Поиск книги по идентификатору.
- Выдача книги и изменение её доступности.
- Возврат книги в библиотеку.
- Сообщения об ошибке при выдаче отсутствующей или уже выданной книги.

Свойство `IsAvailable` показывает доступность книги: `true` - доступна для выдачи, `false` - выдана.

## Установка

1. Установите .NET 8 и Visual Studio со средствами разработки на C#.
2. Откройте решение `LibraryApp.sln`.
3. Выберите «Сборка, Собрать решение».
4. Запустите приложение сочетанием `Ctrl + F5`.

## Использование

1. Запустите приложение.
2. Просмотрите результаты поиска, выдачи и возврата книг в консоли.
3. Для проверки других сценариев измените вызовы методов в `Program.cs` и запустите программу повторно.

В `Main` добавляются три книги: «Властелин колец», «Сияние» и «Война и мир». Затем выполняются демонстрационные операции. Данные задаются в коде; ввод через консоль не предусмотрен.

Для пошаговой проверки установите точки останова в `FindBook`, `BorrowBook` и `ReturnBook`, запустите отладку клавишей `F5`. Используйте `F10` для выполнения следующего шага и `F11` для входа в метод.

## Структура проекта

- `Book.cs` - класс книги со свойствами `Id`, `Title`, `Author` и `IsAvailable`.
- `Library.cs` - хранение списка книг, добавление, поиск, выдача и возврат.
- `Program.cs` - точка входа и примеры операций с книгами.
- `LibraryApp.csproj` - настройки проекта, анализаторов и генерации XML-документации.
- `LibraryApp.sln` - решение Visual Studio.
- `TEST_REPORT.md` - методика тестирования, найденные дефекты и результаты инспекции кода.

## Данные

Книги хранятся в памяти в списке `List<Book>`. При завершении приложения данные не сохраняются. При следующем запуске список создаётся заново в методе `Main`.

## Тестирование и инспекция кода

Использовались ручное тестирование, пошаговая отладка и статический анализ. Проверялись выдача отсутствующей книги, повторная выдача и возврат невыданной книги. Для публичных классов, свойств и методов добавлены XML-комментарии.

Результаты описаны в TEST_REPORT.md.
